# Support

## Using the application

Start with the [README](README.md) for installation, preparing a presentation, live output, phone control, media and live captions. The application's Settings page also includes guided practice and help with individual pages.

Download official Windows and macOS installers from [GitHub Releases](https://github.com/semiromest/Worship-Presentation-Assistant/releases). Include whether you use an installer or a source build when asking for help. Linux installers are not currently published by the configured release workflow.

## Questions and troubleshooting

Search the [issue tracker](https://github.com/semiromest/Worship-Presentation-Assistant/issues) first. If your question is not covered, open an issue explaining what you are trying to do, what happened and which part is unclear. English and Turkish reports are welcome.

For a reproducible defect, use the **Bug report** form. For a proposed change, use **Feature request** and describe the user problem. Reports about incorrect translations should include the interface language, the screen and the suggested wording.

Useful details include:

- The app version and operating system version.
- A short sequence of steps and the expected result.
- For display problems, the number of screens, their resolutions and the affected output.
- For media or import problems, the file format and a small, non-private example if possible.
- A screenshot or short recording with personal information removed.

GitHub issues are public. Remove credentials, tokens, private links, QR codes and confidential presentation content before sharing logs or screenshots. Presentation files can include embedded images, videos and text.

## Private concerns

- **Security vulnerabilities:** follow the [Security Policy](SECURITY.md).
- **Harassment or other conduct concerns:** follow the [Code of Conduct](CODE_OF_CONDUCT.md).

Support is provided as maintainer and community availability allows. There is no guaranteed response time or live-service support commitment. Back up important presentations before troubleshooting changes to files or application data.
