Animated line-round icons from https://gentleface.com, release 0.3.0 (MIT).
Original SVGs are bundled locally; no runtime network request is made.

Motion files: audio-lines-meter, mic-level, broadcast-reach, scissors-snip,
check-circle-draw, loader-step, sync-chase, images-deal, projector-throw,
timer-countdown-wind. Source: https://gentleface.com/motion/index.json.

MotionIcon isolates SVG mask/clip IDs per instance, pauses hidden icons, and
respects both the application's animation preference and reduced motion.
